# MU Construction Dashboards and Workspaces

Role-oriented, read-through workspaces over the standard and construction source models. The module does not create a parallel KPI table: project portfolio values are computed from contracts and the latest non-cancelled monthly close per contract, while operational counters are grouped from their source documents.

Executive monetary values are converted to company currency and restricted to Construction Managers. Every project KPI has a drill-down to its source model. Reading a dashboard creates no operational, stock, or accounting document.

Rollback: revert the module commits and upgrade the affected database in a new Development build. Preserve any user favourites and exported views before uninstalling; the module itself stores no dashboard facts.
