# MU Constructions General — Odoo 19

Version-controlled extensions for the integrated construction ERP implementation.

## Add-ons

- `mu_construction_core`: shared construction reference context for projects, WBS,
  cost codes, and site locations. The module is deliberately not auto-installed.

## Safety

- Development is performed on the Odoo.sh `main` development branch by explicit
  project-owner instruction.
- No module is installed or upgraded without a separate approval.
- No accounting entry or business transaction is created by repository changes.
